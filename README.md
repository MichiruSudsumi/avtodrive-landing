# AVTODRIVE — шаблон лендинга импорта авто

Одностраничный лендинг для компаний, привозящих автомобили из-за рубежа «под ключ».
Структура — по образцу одномарочных лендингов (оффер, комплектации с выгодой, отзывы,
7 шагов, акция с таймером, квиз), визуальный стиль — тёмный премиум с янтарным акцентом.

## Запуск

```bash
npm install
npm run dev      # dev-сервер (аргументы --host/--port пробрасываются в Vite)
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Как заменить марку/модель

Весь контент вынесен в **один файл** — `src/content.ts`: название бренда, модель, цены,
комплектации, отзывы, шаги, FAQ, города, контакты, юридические данные. Вёрстку менять
не нужно. Изображения — в `src/assets/`.

## Структура

- `src/sections/` — секции лендинга (шапка, hero, карточки комплектаций, отзывы,
  акция с таймером, менеджер, шаги, лид-магнит, о компании, FAQ, подвал)
- `src/components/QuizModal.tsx` — квиз-модал «Рассчитать стоимость» (3 шага + экран успеха)
- `src/components/Reveal.tsx` — появление блоков при скролле
- Заявки сохраняются в `localStorage` (ключ `avtodrive_leads`) — подключите свой бэкенд/CRM

## Демо-данные

Бренд «AVTODRIVE», модель «AURORA X6», контакты и реквизиты — вымышленные, для демонстрации шаблона.
